oioi

Small app. Big clipboard energy.

🪟

Real liquid glass

Genuine desktop blur behind the panel — not a flat overlay. Tune blur, corners and frost to taste.

⚡️

Instant

Pre-warmed and snappy. Hit ⌥V and it's already there — Soft mode opens with zero capture lag.

🎛

Soft or Glass

Pick a lightweight flat-white panel, or the full liquid-glass blur. Your call, in Settings.

🔎

Text · Images · Files

Everything you copy, captured. Search instantly and filter by type or date.

🦥

Menu bar & system tray

No Dock clutter. A friendly sloth sits in your menu bar (or system tray) — click it or use the global shortcut.

❤️

Free & open source

No subscription, no account, no telemetry. Built with Electron, all on GitHub.

Three keys to clipboard zen

⌕

Get oioi

Free on every desktop. macOS 12+, Windows 10+, modern Linux.

macOS (.dmg) Windows (.exe) 🐧 Linux (.AppImage)
macOS is a Universal build (Apple Silicon + Intel). Windows & Linux are on the releases page.
First launch: oioi is free and not OS-vendor-signed, so you'll see a one-time prompt. macOS: right-click the app → Open → Open (or xattr -dr com.apple.quarantine /Applications/oioi.app). Windows: SmartScreen → More info → Run anyway. Linux: chmod +x oioi-*.AppImage then run it.
